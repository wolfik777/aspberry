# aspberry · Сем мяу!

Фан-журнал о Тане, которая ведёт канал [aspberry на Twitch](https://www.twitch.tv/aspberry). Выпуск от 4 ноября 2026 года выходит на русском и японском. На обложке — три котёнка под сакурой. Из выпуска можно перейти к записи хэллоуинского эфира, двум клипам зрителей и недавним играм из профиля Steam. Звук включается по желанию.

## Публикация на GitHub Pages с Android

Сохраните `aspberry-site.zip` в обычные «Загрузки». Если Termux ещё не имеет доступа к ним, один раз выполните `termux-setup-storage` и разрешите доступ в Android. Затем вставьте строку целиком:

```sh
pkg install -y unzip && asp_dir=$(mktemp -d) && unzip -q "$HOME/storage/downloads/aspberry-site.zip" -d "$asp_dir" && bash "$asp_dir/publish.sh"
```

При первом входе подтвердите код на GitHub под именем `wolfik777`. Скрипт создаёт отдельный публичный репозиторий `wolfik777/aspberry-site`, если его ещё нет. При повторном запуске он обновляет узнаваемый проект или принимает новый репозиторий с единственным стандартным заголовком README. Ветка — `main`, источник публикации — `/docs`. Действующий адрес после сборки: https://wolfik777.github.io/aspberry-site/ . Японская версия: https://wolfik777.github.io/aspberry-site/ja.html .

Если GitHub ещё собирает сайт, скрипт выведет ссылку на статус. В Settings → Pages должен быть выбран **Deploy from a branch → main → /docs**. Если настройка недоступна, проверьте, что вы вошли как администратор `wolfik777/aspberry-site`. Не загружайте на GitHub один ZIP — Pages нужны распакованные файлы.

## Просмотр и правки

После распаковки можно открыть `docs/index.html` в браузере на компьютере. Сайт не требует сервера, npm, ключей API или внешних библиотек. Выйти на Twitch, Steam, Telegram и Discord можно при подключении к интернету.

- `docs/` — готовый сайт, в том числе фотографии, обложки, шрифты и переключатель языков.
- `src/edition.mjs` — тексты, даты, ссылки и команды. `src/art.mjs` — векторная графика.
- `scripts/render.mjs` — HTML, метаданные, карта сайта. `scripts/check.mjs` проверяет обе версии, метаданные, внутренние ссылки и медиа.
- `docs/assets/site.css` и `docs/assets/site.js` — оформление и поведение.

После правок из корня распакованного архива, если установлен Node.js 18 или новее:

```sh
ASPBERRY_OUTPUT=docs node scripts/render.mjs
node scripts/check.mjs
bash publish.sh
```

При собственном домене укажите полный адрес каталога с завершающей косой чертой через `ASPBERRY_BASE_URL` при рендере и проверке. Скрипт публикации рассчитан именно на `wolfik777/aspberry-site`. Для поисковых систем уже подготовлены отдельные URL и заголовки, `hreflang`, canonical, JSON-LD, `sitemap.xml` и изображение для ссылок. После публикации владелец может добавить `https://wolfik777.github.io/aspberry-site/sitemap.xml` в Google Search Console.
